Detailed Description

template<unsigned mod>
struct RollingHash< mod >

文字列の一致判定を高速に行う

Template Parameters
mod1000000007などを入れる
Author
ei1333

https://ei1333.github.io/luzhiled/snippets/string/rolling-hash.html

使い方： using RH = RollingHash< 1000000007 >; RH rh(S);

get：区間[l, r)のハッシュ値を得る x = rh.get(l, r);

connect：ハッシュ値 h1, 長さ h2len のハッシュ値 h2 を結合する x = rh.connect(h1, h2, len);

LCP：区間[l1, r1)とハッシュテーブルが b の区間[l2, r2)の最長共通接頭辞の長さを求める x = rh.LCP(rhb, l1, r1, l2, r2);

計算量： 構築 O(N) get O(1) connect O(1) LCP O(logN)
